# 📄 PDF Merger — WebHubCode

A fast, privacy-first PDF merging tool that runs **entirely in your browser**. No uploads, no servers, no data collection.

## ✨ Features

- 🔒 **Privacy first** — files never leave your browser
- 📂 **Drag & drop** — add multiple PDFs instantly
- 🔃 **Reorder files** — drag or use ↑ ↓ buttons
- ⚡ **Fast merge** — powered by pdf-lib
- 📊 **Progress bar** — real-time merge status
- 💾 **Custom filename** — name your output file
- 📱 **Responsive** — works on all devices
